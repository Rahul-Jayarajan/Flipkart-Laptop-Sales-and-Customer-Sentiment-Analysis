# 📊 Laptop Market Analysis Dashboard

## Overview
This project analyzes laptop market data sourced from Flipkart using Python, SQL, and Power BI. The goal was to clean and transform raw data, perform exploratory data analysis (EDA), uncover business insights through SQL queries, and develop an interactive dashboard for data-driven decision-making.

---

## 🎯 Project Objectives

- Analyze laptop market trends and pricing patterns
- Compare laptop brands, ratings, and specifications
- Identify factors influencing laptop prices
- Perform SQL-based business analysis
- Build an interactive Power BI dashboard

---

## 📂 Dataset

**Source:** Flipkart Laptop Listings

### Dataset Features
- Brand
- Price
- Rating
- Processor
- RAM
- Storage
- Operating System
- Graphics Card
- Gaming Laptop Indicator

## 🔄 Project Workflow

### 1. Data Cleaning
- Removed duplicate records
- Handled missing values
- Standardized data formats

### 2. Exploratory Data Analysis (EDA)
- Brand-wise laptop distribution
- Price analysis
- Rating analysis
- Gaming vs Non-Gaming comparison
- RAM and Storage trends

### 3. SQL Analysis
Performed SQL queries to identify:
- Top laptop brands
- Average laptop prices
- Rating distribution
- Gaming laptop trends
- Configuration-based insights

### 4. Power BI Dashboard
Created an interactive dashboard featuring:
- KPI Cards
- Brand Analysis
- Price Distribution
- Rating Analysis
- Gaming Laptop Analysis
- Interactive Filters & Slicers

---

## 📈 Dashboard KPIs

- Total Laptops
- Average Price
- Average Rating
- Gaming Laptop Count
- Brand Count

---

## 🔍 Key Insights

- HP, Lenovo, and ASUS dominate the laptop market.
- Gaming laptops command significantly higher prices.
- Higher RAM configurations generally lead to increased pricing.
- Certain brands provide better value based on price-to-rating ratio.
- Mid-range laptops represent the largest market segment.
